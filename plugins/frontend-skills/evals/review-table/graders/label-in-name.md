The review reports that the `aria-label` of the systems link ("Show the systems of {name}") replaces its visible text, the number of systems, so the spoken name doesn't contain what users see (WCAG 2.5.3, label in name). It suggests keeping the visible text in the name, for example with hidden text after it instead of the `aria-label`.
