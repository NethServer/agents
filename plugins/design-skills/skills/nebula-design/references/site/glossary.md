# Glossary

> Mirror of https://nethesis.github.io/nebula-design-system/?page=glossary, synced on 2026-11-10 by `scripts/sync_site.py`. Do not edit: the site is the source of truth. If the live site disagrees, follow the site.

Approved terms of Nethesis user interfaces, with their Italian translation (it) and the terms to avoid. untranslatable: keep the English term in Italian too. products lists the products a term applies to, all for every product. link is the term in the Glossary page, to cite in reviews.

Use the English term in the UI copy of mockups; the Italian column is for translations and reviews.

| Term | Italian | Definition | Avoid (en) | Avoid (it) | Products | Notes |
|---|---|---|---|---|---|---|
| **System key** | Chiave di sistema | The public identifier of a system registered on My Nethesis. | System ID | Chiave sistema, ID sistema | My Nethesis, NethServer 8, NethSecurity | Example: "NETH-1234-5678-9ABC-DEF0-1234-5678-9ABC-DEF0". |
| **System secret** | Segreto di sistema | The credential a system uses to connect to My Nethesis. It is shown only once, when it is generated. | System token, Registration token, Authentication token | Segreto del sistema, Token di sistema, Token di registrazione, Token di autenticazione | My Nethesis, NethServer 8, NethSecurity | Example: "my_0123456789abcdef0123.0123456789abcdef0123456789abcdef01234567". In Italian, use "Segreto di sistema" like "Chiave di sistema"; "il segreto del sistema <name>" is fine only for a specific system. |
| **Subscription** | *Keep in English* | The plan of a registered system, such as Community or Enterprise. | Registration | Abbonamento, Sottoscrizione | All products | Do not call the subscription a "registration". Registering a system, that is connecting it to My Nethesis, is fine: "Register system". |
| **Add-on** | *Keep in English* | An optional feature bought on NethShop and granted to a system, such as Threat Shield. | Entitlement, Addon, Additional service | Servizio aggiuntivo | All products | The Italian plural does not change: "gli add-on". |
| **Tier** | Fascia | The size of an add-on sold by size, that is how many devices or applications it covers. |  | Livello | My Nethesis | A system that goes beyond its tier is "Over the tier" ("Oltre la fascia"). For the level of a subscription, such as Community or Enterprise, use "Plan" ("Piano"). |
| **NethShop** | *Keep in English* | The Nethesis online shop for Nethesis products and services, such as add-ons, appliances and training. | Nethshop |  | My Nethesis |  |
| **Company** | Azienda | A distributor, a reseller or a customer in My Nethesis, with its users and systems. | Organization | Organizzazione | My Nethesis | Use "Company" for the generic case; use "Distributor", "Reseller" or "Customer" when the level matters. |
| **Threat Shield** | *Keep in English* | A security service that blocks malicious IP addresses and domains using blocklists. | Threat shield, ThreatShield |  | NethSecurity, NethServer 8 | Its parts are "Threat Shield IP" and "Threat Shield DNS". |
| **MultiWAN** | *Keep in English* | The NethSecurity feature that uses several internet connections together, for load balancing or failover. | Multi WAN, Multi-WAN |  | NethSecurity |  |
| **FlashStart** | *Keep in English* | A third-party cloud filter that blocks unwanted websites through DNS, integrated in NethSecurity. | Flashstart |  | NethSecurity, My Nethesis |  |
| **Blocklist** | *Keep in English* | A list of items that are blocked, such as IP addresses or domains. | Blacklist, Block list | Blacklist, Lista nera | NethSecurity, NethServer 8 | Its opposite is "Allowlist". |
| **Allowlist** | *Keep in English* | A list of items that are always allowed, such as IP addresses or domains, even when a blocklist contains them. | Whitelist, Allow list | Whitelist, Allow list, Lista bianca | NethSecurity, NethServer 8 | Its opposite is "Blocklist". |
| **Create** | Crea | Make a new object that did not exist before, such as a user, a group or a firewall rule. | New, Add |  | All products | Name the object: "Create user". Use "Add" when the object already exists and is only associated with another one. |
| **Add** | Aggiungi | Associate an object that already exists, for example add a user to a group. | Create, New |  | All products | Use "Create" when the object does not exist yet and is made from scratch. |
| **Edit** | Modifica | Change the data of an object. | Modify | Cambia | All products | To replace a single value, such as a password, use "Change". |
| **Change** | Cambia | Replace a single value with a new one, such as a password, a picture, the language or the number of licenses. | Modify | Modifica | All products | "Change password" ("Cambia password"). For the data of an object, use "Edit". As a noun, "change" is "modifica": "Change history" ("Cronologia modifiche"). |
| **Delete** | Elimina | Permanently destroy an object, such as a contact, a firewall rule or a user. | Remove | Cancella, Rimuovi | All products | Use "Remove" when the object only leaves a list or an association and still exists, for example a user removed from a group. For applications, use "Uninstall". When the deletion has consequences beyond the object itself, ask for confirmation first: see Delete confirmation in the guidelines. In My Nethesis, which archives objects before deleting them, the permanent action is "Destroy". |
| **Remove** | Rimuovi | Take an object out of a list or an association without destroying it, for example remove a user from a group. | Delete | Elimina | All products | Use "Delete" when the object is destroyed. |
| **Uninstall** | Disinstalla | Remove an application, with its data, from NethServer 8. | Delete, Remove | Elimina, Rimuovi | NethServer 8 | Name the application: "Uninstall mail1". |
| **Archive** | Archivia | Take an object out of use without destroying it, so that it can be restored, such as a user, a system or a company. | Deactivate, Trash, Move to trash |  | My Nethesis | Only in products that keep archived objects. Its opposite is "Restore"; the action that removes an archived object for good is "Destroy". |
| **Restore** | Ripristina | Bring back something kept earlier, such as an archived object or the configuration saved in a backup. | Unarchive, Recover, Reactivate, Undelete |  | All products | "Restore user" ("Ripristina utente"), "Restore backup" ("Ripristina backup"). For default values, use "Reset". |
| **Destroy** | Elimina definitivamente | Permanently delete an archived object, which can no longer be restored. | Purge, Erase, Delete permanently, Permanently delete |  | My Nethesis | Only in products that archive objects before deleting them, where it takes the place of "Delete". In Italian, drop "definitivamente" when the object follows: "Destroy user" ("Elimina utente"). |
| **Enable** | Abilita | Turn on a feature or an option. | Activate | Attiva | All products | The resulting state is "Enabled" ("Abilitato", not "Attivato"). |
| **Disable** | Disabilita | Turn off a feature or an option. | Deactivate | Disattiva | All products | The resulting state is "Disabled" ("Disabilitato", not "Disattivato"). |
| **Clear** | Azzera | Empty a search field, a selection or a filter. |  | Pulisci, Svuota, Cancella | All products | "Clear" empties values; "Reset" brings them back to their defaults. For filters, use "Clear selection" ("Azzera selezione") only inside a single dropdown filter that has nothing selected by default, "Clear filter" ("Azzera filtro") when the only filter of a table or a collection is a text filter, and "Reset" in every other case: see the Table filters guidelines. The clear button of a search field is "Clear search" ("Azzera ricerca"). |
| **Reset** | Reimposta | Bring values back to their defaults, for example the filters of a list. |  | Ripristina | All products | "Reset filters" ("Reimposta filtri"), "Reset selection" ("Reimposta selezione"), "Reset password" ("Reimposta password"). In Italian, "Ripristina" is for restoring a backup. |
| **Cancel** | Annulla | Abandon an unfinished action, such as a form or a confirmation, without saving anything. | Abort, Dismiss | Cancella | All products | In Italian "Cancella" means delete, so it would suggest that data is lost. To dismiss information with no pending changes, use "Close" ("Chiudi"): see Buttons and actions in the guidelines. |
| **Details** | Dettagli | The button that opens the page of an object, in a table row or a card. | View, See details, View details | Visualizza | All products | An exception to the verb rule for buttons, for brevity: always with the eye icon, and with the object name for screen readers. "Show details" is for content that opens in place. |
| **Show** | Mostra | Make content visible in place, such as a password, more rows or the notifications. | View, See | Visualizza, Vedi | All products | Its opposite is "Hide" ("Nascondi"). "Show more" ("Mostra di più"), "Show password" ("Mostra password"). To open the page of an object, use "Details"; to open another page, use "Go to". |
| **Hide** | Nascondi | Make content that was shown in place invisible again, such as a password. |  |  | All products | Its opposite is "Show" ("Mostra"). "Hide password" ("Nascondi password"). |
| **Collapse** | Comprimi | Reduce a section, a card or a group to its title, hiding its content. | Close, Reduce | Collassa, Riduci, Chiudi | All products | Its opposite is "Expand" ("Espandi"). "Collapse all cards" ("Comprimi tutte le card"). To make content disappear entirely, use "Hide". |
| **Expand** | Espandi | Open a collapsed section, card or group to show its content. |  |  | All products | Its opposite is "Collapse" ("Comprimi"). "Expand all cards" ("Espandi tutte le card"). |
| **Download** | Scarica | Save a file from the product to the user's computer, such as a backup or a report. |  |  | All products | Its opposite is "Upload" ("Carica"). As a noun for network traffic, it stays in English: "Download speed" ("Velocità di download"). |
| **Upload** | Carica | Send a file from the user's computer to the product, such as a certificate or a backup. |  |  | All products | Its opposite is "Download" ("Scarica"). As a noun for network traffic, it stays in English: "Upload speed" ("Velocità di upload"). |
| **Sign in** | Accedi | Enter a product with your credentials. | Log in, Login, Signin | Login, Effettua il login | All products | "Login" is fine as a noun or modifier: "Login failed", "last login", "root login". Queue login in NethVoice is a different concept: agents "log in to" and "log out of" a queue. |
| **Sign out** | Esci | Leave a product and end your session. | Log out, Logout, Log off | Disconnetti, Logout | All products |  |
| **Username** | Nome utente | The name a user signs in with. | User name | Utente, Username | All products | Translate it also in short labels: "Username and password" is "Nome utente e password", not "Utente e password". |
| **Two-factor authentication** | Autenticazione a due fattori | A sign-in that asks for a second proof besides the password, such as a code from an authenticator app. | Two-Factor Authentication, Two factor authentication, Two-step verification | Autenticazione a 2 fattori, Doppio fattore | NethServer 8, NethSecurity, NethVoice | Sentence case: "Two-factor authentication". In short labels, after the full name appears on the page, "2FA" is fine: "Revoke 2FA" ("Revoca 2FA"). |
| **Alert** | Allarme | A notice raised when a monitored condition needs attention, such as a full disk or too many calls waiting in a queue. | Alarm |  | All products |  |
| **Backup destination** | Destinazione di backup | A storage location where backups are saved. | Backup repository | Repository di backup | NethServer 8 |  |
| **My Nethesis** | *Keep in English* | The Nethesis administration portal, where systems are registered and managed. | My, my.nethesis.it |  | All products | Write "My Nethesis" in full. "My" is only an informal short form, not used in user interfaces. To refer to it indirectly, "Nethesis administration portal" ("portale di amministrazione Nethesis") is also correct. |
| **NethServer** | *Keep in English* | The Nethesis open source server for small and medium businesses. From a web interface, it installs and manages applications, such as mail, file sharing and NethVoice, on one or more nodes. | Nethserver, NS8 |  | All products | "NethServer 8", with the version, is also correct. Do not shorten it to "NS8". |
| **Cluster** | *Keep in English* | A group of NethServer nodes managed together from one web interface. |  |  | NethServer 8, My Nethesis | A cluster has one leader node; the other nodes are worker nodes. |
| **Node** | Nodo | A server that is part of a NethServer cluster and runs its applications. |  |  | NethServer 8, My Nethesis | "Leader node" ("Nodo leader") manages the cluster; the others are "Worker node" ("Nodo worker"). |
| **Hostname** | Nome host | The name of a server or a unit on the network, such as a node or a NethSecurity unit. | Host name | Hostname | NethServer 8, NethSecurity, NethVoice | Lowercase inside a sentence: "Change the hostname" ("Cambia il nome host"). |
| **Storage** | *Keep in English* | The disk space where a system keeps its data, such as logs, backups or the data of its applications. |  | Archiviazione, Spazio di archiviazione | NethServer 8, NethSecurity, My Nethesis | In Italian it is masculine: "lo storage", "Storage locale". |
| **NethSecurity** | *Keep in English* | The Nethesis open source firewall for small and medium businesses, based on OpenWrt. Many installations can be managed from NethServer 8 with the NethSecurity controller. | Nethsecurity, Nsec |  | All products | Each installation is called a "unit". |
| **Unit** | Unità | A single NethSecurity installation, such as one managed by the NethSecurity controller. | Firewall unit, Firewall, Device | Unità firewall, Dispositivo, Firewall | NethSecurity | Call the installation "unit", also in technical texts: "The unit IP address", "Reset the unit". "Firewall" stays correct for the feature, as in "firewall rules", and for the kind of product, as in "NethSecurity is a firewall". |
| **NethVoice** | *Keep in English* | The Nethesis business phone system (VoIP PBX), installed as an application on NethServer 8. It includes NethVoice CTI, the web app users make and receive calls with, NethLink, its desktop app, and a mobile app also called NethVoice. | Nethvoice |  | All products |  |
| **NethVoice CTI** | *Keep in English* | The NethVoice web app for users, to make and receive calls and manage contacts, call history and presence. | NethCTI, CTI |  | NethVoice | Write the full name. Exception: inside NethVoice, "CTI" alone is fine when the context is clear. The mobile app is called "NethVoice", not "NethCTI". |
| **NethLink** | *Keep in English* | The NethVoice CTI desktop app. It shows call notifications even when the browser is closed and supports click-to-call. | Nethlink |  | NethVoice |  |
| **Application** | Applicazione | Software installed on NethServer 8 from the Software center, such as Mail, Nextcloud or NethVoice. | App | App | NethServer 8, My Nethesis | Always prefer "Application" to "Instance"; use "Instance" only when strictly necessary. "App" is fine for mobile and desktop apps, such as NethLink or the NethVoice mobile app. |
| **Instance** | Istanza | A single installed copy of an application, such as mail1. The same application can be installed more than once. |  |  | NethServer 8 | Use "Instance" only when the context strictly requires one specific copy of an application, and "Application" would be misleading: for example, to choose among several copies of the same application ("Choose a NethVoice instance"). In every other case, use "Application". |
| **WebTop** | *Keep in English* | The groupware application for mail, calendars, contacts and shared documents, installed on NethServer 8. | Webtop |  | NethServer 8, NethService |  |
| **Nextcloud** | *Keep in English* | The third-party application for file sharing and collaboration, installed on NethServer 8. | NextCloud |  | NethServer 8, NethService |  |
