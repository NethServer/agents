# Components and patterns of @nethesis/vue-components (v3.16.0)

> Mirror of https://nethesis.github.io/vue-components/, synced on 2026-11-10 by `scripts/sync_site.py`. Do not edit: the site is the source of truth. If the live site disagrees, follow the site.

The components of @nethesis/vue-components and the patterns, ready-made combinations of components for a whole interaction. Use a pattern when it covers the task, a component otherwise, and never a deprecated component: use its replacedBy. parts are components documented with the one that contains them. storiesSource is the code of the stories, with the usage of the component; componentSource is the code of the component. The Storybook is built from the main branch, which may have changes not released yet; version is the latest release. Check the props of the installed version in node_modules/@nethesis/vue-components/dist/components/<Name>.vue.d.ts. The rules for texts, icons and colors are in the Nebula Design System: designSystem lists its files, and descriptions link the sections of the writing guidelines that the texts follow.

## Patterns

Start from these when they cover the task.

| Pattern | Main component | What it is | Storybook |
|---|---|---|---|
| **Create item drawer** | NeSideDrawer | The form to create an object, in an `NeSideDrawer` opened by the create button of the page: the fields, an `NeInlineNotification` when the save fails, and the footer with Cancel and the button that saves. The same drawer edits an object: then its title is Edit <object> and the button is Save. The first field gets the focus when the drawer opens, and Enter in a field saves. After saving, the drawer closes and the product shows the Success toast notification pattern. Its texts follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) and [Error messages](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#error-messages) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-create-item-drawer--standard |
| **Delete item modal** | NeModal | The confirmation before deleting an object: an `NeModal` of kind warning with a danger button. The Type to confirm version asks the user to type the name of the object, for deletions that lose a lot of data. Its texts follow [Delete confirmation](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#delete-confirmation) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-delete-item-modal--standard |
| **Empty state** | NeEmptyState | The empty states of a page or a list: no objects yet, no objects configured, no results for a search or a filter, and a page the user cannot access. Its texts follow [Empty states](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#empty-states) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-empty-state--no-items |
| **Inline error notification** | NeInlineNotification | The error shown inside a page or a form when an action fails, such as saving: a network error or a generic one. Its texts follow [Error messages](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#error-messages) and [Inline notifications](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#inline-notifications) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-inline-error-notification--network-error |
| **New password form** | NePasswordRequirements | The form to set a new password: the password with its requirements, checked while the user types, and its confirmation. Its texts follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-new-password-form--standard |
| **Success toast notification** | NeToastNotificationV2 | The toast notification shown after an object is created, updated or deleted, with its texts. Its texts follow [Success notifications](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#success-notifications) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-success-toast-notification--item-created |
| **Table page** | NeTable | A page that lists objects in a table: the description of the page with the create button, the toolbar with search, filters and sorting, the table with the actions of each row and the paginator, and the loading and empty states. Without a description, the create button goes on the right of the toolbar, or above it on small screens. With no objects yet, the create button is only in the empty state. Its texts follow [Page header](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#page-header), [Table filters](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#table-filters) and [Empty states](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#empty-states) in the writing guidelines. | https://nethesis.github.io/vue-components/?path=/story/patterns-table-page--standard |

## Components

| Component | What it is for | Parts | Storybook |
|---|---|---|---|
| **NeAvatar** | The picture of a user or an account; without a picture, their initials or a user icon. `squared` makes it a square with rounded corners instead of a circle. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neavatar--docs |
| ~~NeBadge~~ → use NeBadgeV2 | Deprecated: use NeBadgeV2 instead. This component will be removed in a future release. To switch, move `text` and the icon into the default slot of NeBadgeV2, the icon as a `FontAwesomeIcon` before or after the text. The kinds become colors: `primary` stays, `secondary` becomes `gray`, `tertiary` `indigo`, `success` `green`, `warning` `amber`, `error` `rose` and `info` `blue`. `rounded` becomes `pill`, `customColorClasses` becomes `customKindClasses`, and an icon that removes the badge becomes `dismissable`, with the `dismiss` event. `label` has no replacement. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nebadge-deprecated--docs |
| **NeBadgeV2** | A short label for a status or a category, such as Enabled, Expired or Admin, next to the object it describes. `dismissable` adds a button to remove it, for example to remove an active filter. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nebadgev2--docs |
| **NeButton** | Starts an action. `primary` is the main action of a view or a dialog, and there is only one; `secondary` is for the other actions, `tertiary` for minor ones, `danger` to confirm a destructive action. Bind `loading` while the action runs. To go to another page, use `NeLink`. Its texts follow [Buttons and actions](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#buttons-and-actions) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nebutton--docs |
| **NeCard** | A box that groups the content of a section, with an optional title, icon and menu of actions. It shows its own loading skeleton and error message, so each card of a dashboard can load on its own. |  | https://nethesis.github.io/vue-components/?path=/docs/components-necard--docs |
| **NeCheckbox** | A single checkbox, with a label and an optional description. To choose several among a few options, use `NeCheckboxCards`; for a setting that is turned on or off, `NeToggle`. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-necheckbox--docs |
| **NeCheckboxCards** | A group of checkboxes shown as cards, each with a label and an optional description, icon or image, to choose several among a few options, all visible. For many options, use `NeMultiselectCombobox`; to choose only one, `NeRadioSelection` with `card`. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-necheckboxcards--docs |
| **NeCombobox** | A field to choose one option from a long list, typing to filter it. `acceptUserInput` also accepts a value that is not in the list. For a short list, use `NeListbox`. `multiple` is deprecated: to choose several options, use `NeMultiselectCombobox`. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-necombobox--docs |
| **NeDropdown** | A menu of actions opened by a button, by default three vertical dots: the actions of a table row, a card or a page. To filter a list, use `NeDropdownFilterV2`; to sort it, `NeSortDropdown`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nedropdown--docs |
| ~~NeDropdownFilter~~ → use NeDropdownFilterV2 | Deprecated: use NeDropdownFilterV2 instead. This component will be removed in a future release. NeDropdownFilterV2 has the same props and events, but its `v-model` holds the selected options, not their ids. The types `FilterOption` and `FilterOptionGroup` become `NeDropdownFilterV2Option` and `NeDropdownFilterV2OptionGroup`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nedropdownfilter-deprecated--docs |
| **NeDropdownFilterV2** | A button that opens the values of a filter, in the toolbar above a table or a list. `kind` sets one value (`radio`) or several (`checkbox`). Options can be grouped. A search field appears with `showOptionsFilter`, or when there are more options than `maxOptionsShown`. With `checkbox`, the button shows how many values are selected. Its texts follow [Table filters](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#table-filters) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nedropdownfilterv2--docs |
| **NeEmptyState** | Takes the place of a list, a table or a page with nothing to show: an icon, a title, a description and, when there is a next step, an action. Follow the Empty state pattern for its texts. Its texts follow [Empty states](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#empty-states) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neemptystate--docs |
| **NeExpandable** | A label that shows and hides the content below it, for advanced settings or details that would make a page too long. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neexpandable--docs |
| **NeFileInput** | A field for one file: an area where the user drops the file or clicks to choose it, with an optional progress bar for the upload. `accept` filters the file picker only, not dropped files: check the type of the selected file. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nefileinput--docs |
| **NeFormItemLabel** | The label of a form field built without the form components, which have their own `label` prop. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neformitemlabel--docs |
| **NeHeading** | A heading: `tag` sets the level, from `h1` to `h6`, and the matching text style. One `h1` per page, for its title. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neheading--docs |
| **NeInlineNotification** | A message inside a page, a form or a dialog, that stays until the problem is solved or the user closes it: an error after an action, a warning, or information about the content around it. Buttons and `details` are optional. For the result of an action, shown for a few seconds, use `NeToastNotificationV2`. Its texts follow [Notifications](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#notifications) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neinlinenotification--docs |
| **NeLink** | A text link, to another page or to an external site, or for a minor action inside text. `invertedTheme` is for a background of the opposite theme, such as inside a tooltip. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nelink--docs |
| **NeListbox** | A field to choose one option from a short list, without typing: the equivalent of a select. For a long list that needs searching, use `NeCombobox`. To choose several options, use `NeCheckboxCards` for a few and `NeMultiselectCombobox` for many. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nelistbox--docs |
| **NeModal** | A dialog over the page, for a confirmation, a short form or a message that needs an answer before going on. `kind` sets the icon; it has up to three buttons: primary, secondary and cancel. For a deletion, follow the Delete item modal pattern; for a long form or for details, use `NeSideDrawer`. Its texts follow [Modals](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#modals) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/story/components-nemodal--neutral |
| **NeMultiselectCombobox** | A field to choose several options from a long list, typing to filter it. The chosen options are shown as badges. For a few options, use `NeCheckboxCards`; to choose only one, `NeCombobox`. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nemultiselectcombobox--docs |
| **NePaginator** | The page navigation of a table or a list, with the range of rows shown and the number of rows per page. It goes in the `paginator` slot of `NeTable`. In a narrow container the pages wrap below the range and the page size. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nepaginator--docs |
| **NePasswordRequirements** | The requirements of a new password, each marked as met or not while the user types. Use it with `usePasswordRequirements`, as in the New password form pattern. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nepasswordrequirements--docs |
| **NeProgressBar** | How far a task has gone, as a percentage, or `indeterminate` when that is unknown. For a short wait, use `NeSpinner`; while content loads, `NeSkeleton`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neprogressbar--docs |
| **NeRadioSelection** | A group of radio buttons to choose one option among a few, all visible. With `card`, each option is a card with a description, an icon or an image. For many options, use `NeListbox`. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neradioselection--docs |
| **NeRoundedIcon** | An icon in a colored circle that shows the kind of a message: info, warning, error or success. Modals and notifications already include it. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neroundedicon--docs |
| **NeSideDrawer** | A modal panel that slides in from the right over the dimmed page, for a form or details too long for a modal. The page behind it cannot be used until it closes. |  | https://nethesis.github.io/vue-components/?path=/story/components-nesidedrawer--default |
| **NeSkeleton** | Gray lines in place of content while it loads. For a table, use the `loading` prop of `NeTable`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-neskeleton--docs |
| **NeSortDropdown** | A button that opens the sort options of a list or a table: the field to sort by and the direction. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nesortdropdown--docs |
| **NeSpinner** | A small spinning indicator for a short wait. `NeButton` shows it with `loading`. While a page or a section loads, use `NeSkeleton`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nespinner--docs |
| **NeStepper** | The current step of a procedure with several steps, such as a wizard: a progress bar with the step number. |  | https://nethesis.github.io/vue-components/?path=/docs/components-nestepper--docs |
| **NeTable** | A data table, built with `NeTableHead`, `NeTableHeadCell`, `NeTableBody`, `NeTableRow` and `NeTableCell`. Below `cardBreakpoint`, each row becomes a card. Sortable columns emit `sort`, and the product sorts the rows, for example with `useSort`; `useItemPagination` splits the rows into pages for a `NePaginator` in the `paginator` slot. `loading` shows a skeleton. For a whole page that lists objects, follow the Table page pattern. | NeTableHead, NeTableHeadCell, NeTableBody, NeTableRow, NeTableCell | https://nethesis.github.io/vue-components/?path=/docs/components-netable--docs |
| **NeTabs** | Tabs that switch between views of the same page or object. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netabs--docs |
| **NeTextArea** | A text field of several lines, for descriptions, notes and other long text. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netextarea--docs |
| **NeTextInput** | A text field of one line. `isSearch` makes it a search field with a button to clear it; `isPassword` hides the value, with a button to show it. The `prefix` and `suffix` slots add text or an icon inside the field. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netextinput--docs |
| ~~NeToastNotification~~ → use NeToastNotificationV2 | Deprecated: use NeToastNotificationV2 instead. This component will be removed in a future release. To switch, make the notification a `NeNotificationV2`: `primaryLabel` and `secondaryLabel` become `firstButtonLabel` and `secondButtonLabel`. `primaryAction` and `secondaryAction` hold functions, while `firstButtonAction` and `secondButtonAction` hold names: the component emits the name with the `action` event, and the product runs the action. `primaryButtonRightAligned` becomes `firstActionOnRight`. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netoastnotification-deprecated--docs |
| **NeToastNotificationV2** | A notification about the result of an action the user should notice, such as an object created or deleted, with up to two actions. It is only the card: the product shows it in a fixed container at the edge of the screen, and removes it on `close` or after a few seconds. For an error the user has to act on, use `NeInlineNotification`. Follow the Success toast notification pattern. Its texts follow [Notifications](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#notifications) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netoastnotificationv2--docs |
| **NeToggle** | A switch that turns a setting or a feature on or off. Its label, helper text and validation messages follow [Forms](https://nethesis.github.io/nebula-design-system/?page=writing-guidelines#forms) in the writing guidelines. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netoggle--docs |
| **NeTooltip** | Extra information about an element, such as the help icon next to a label. It opens on click by default; `triggerEvent="mouseenter focus"` opens it on hover and focus. Form components have a `tooltip` slot for it. Never put information the user needs only in a tooltip. |  | https://nethesis.github.io/vue-components/?path=/docs/components-netooltip--docs |
